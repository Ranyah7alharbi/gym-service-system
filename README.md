Gym Service System (GSS)

A centralized digital platform for managing gym operations — built as a course project for SE-262 Software Engineering.

About

Gym Service System (GSS) replaces manual, paper-based gym management with a centralized system that connects membership registration, session booking, attendance tracking, and payments in one place. The system supports three types of users — Members, Trainers, and Administrators — each with different access levels.
Features

	•	Authentication — secure login for members, trainers, and administrators
  
	•	Account Registration — new members can create accounts and manage their profiles
  
	•	Membership Subscriptions — browse and subscribe to membership plans
  
	•	Session Booking — book and cancel training sessions with real-time availability
  
	•	Attendance Tracking — automatic attendance recording and history
  
	•	Trainer Schedule Management — trainers manage their sessions and view enrolled members
  
	•	Admin Controls — manage user accounts, membership plans, and view reports
  
	•	Automated Notifications — booking confirmations, reminders, and membership alerts
Tech Stack

	•	Language: Python
  
	•	GUI Framework: Tkinter
